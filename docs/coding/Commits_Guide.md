# Commit Guide

- [Back to index](index.md)

This will make the future history much easier to understand:

| Type | Meaning | Example |
|------|---------|---------|
| feat | new capability | `feat(builder): add generic builder` |
| refactor | structural improvement | `refactor(core): simplify metadata resolution` |
| fix | bug correction | `fix(hierarchy): prevent traversal of invalid node` |
| test | testing | `test(hierarchy): add cyclic hierarchy test` |
| docs | documentation | `docs(architecture): describe definition model` |
| chore | infrastructure/tooling | `chore(config): add linting rules`<br>`chore(ci): update pipeline configuration` |
| perf | performance | `perf(core): reduce metadata lookup overhead` |
| style | formatting | `style(core): format with consistent indentation` |
