# v0.1.0-alpha

[Back to index](index.md)

First alpha of MTPR: a metadata-driven backend platform. Entities, relations, business rules, security and tenancy are defined in JSON files and served as a REST API with no application code.

## Highlights

- **Definition-driven REST API**: generic CRUD endpoints with validation and MTPR-coded errors (M1).
- **Hot reload**: edit definition files while the API runs; the next request uses the change, without a restart.
- **Relations and querying**: SQLite-enforced references (restrict, cascade, set-null), composite uniqueness, filtering, sorting, paging and field selection (M2).
- **Business rules**: computed decimal fields, field defaults, lifecycle states and transitions, and before/after rejection rules, all transactional (M3).
- **Security and multi-tenancy**: OIDC/JWT authentication, entity and field role grants, row-level filters, tenant isolation, and a transactional audit log (M4).
- **Helpdesk sample** (`docs/examples/m5-helpdesk`) built only from configuration, a README quickstart, and a container image (M5).
- **Development token service** (`tools/Mtpr.LocalTokenService`) to run the secured API without an external identity provider.

## Breaking changes

- Unused public utilities were removed from `Mtpr.Core` (builders, repositories, pagination, extension helpers) with their tests. Migrate before upgrading.
- CRUD endpoints require a JWT bearer token. Configure `Mtpr:Authentication:Authority` (HTTPS) and `Mtpr:Authentication:Audience`.

## Known limitations

- Alpha quality; public API and definition schema may change. Changes are recorded in these notes.
- Supported isolation deployment is one API process per SQLite database. The audit log is not a complete security-event log.
- Changing a definition does not backfill existing rows (computed fields, lifecycle, defaults). Required field additions and destructive schema changes are unsupported.
- Rules run only for the directly requested entity, not for cascaded changes.
- `tools/Mtpr.LocalTokenService` is for development only and has no automated tests. Replace its placeholder client secrets.
